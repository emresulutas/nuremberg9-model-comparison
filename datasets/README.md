# Nuremberg Letterbooks

Download and extract the images and labels from [Mayr et al., Nuremberg Letterbooks v1](https://zenodo.org/records/13881575).
Use `datasets/nuremberg/images/` for the images and `datasets/nuremberg/labels/` for the labels.
Set `NUREMBERG_ROOT` to use another absolute dataset directory instead.
The image crops in the reports were polygon-masked, converted to grayscale and, for explanation figures, overlaid with heatmaps.
