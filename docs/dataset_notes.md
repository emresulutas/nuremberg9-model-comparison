# Nuremberg Letterbooks: what we know about the data

Source: Zenodo 13881575 (Mayr et al., Scientific Data 2025, arXiv 2411.07138).
Books Band2 to Band5, 1,711 page images, 10 scribes.

## Files
- `images/BandN/Rst Nbg-Briefbücher-Nr N_0048_right.jpg` (some pages are `_left` / `_right` halves of a spread, some have no suffix)
- `labels/nuremberg_letterbooks/basic/BandN/<k>.xml`: one PAGE XML per page, 1,711 files (256 + 548 + 290 + 617)
- `labels/nuremberg_letterbooks/diplomatic-regularised/BandN/<k>.xml`: about 3,176 files (different split), same line labels
- The XML names its image: `<Page imageFilename="Rst Nbg-Briefbücher-Nr 2_0048_right.png">`. Match by file stem (disk has .jpg).
- The XML file number (`163.xml`) is NOT the image number.
- `labels/nuremberg_letterbooks/` contains its own `.git` folder (the dataset's repo). Never run git commands inside it.

## Labels
- Scribe label is per text line: `<TextLine ... writerID="6">`, with a polygon `Coords` and a `Baseline`.
- 250 lines have several IDs (e.g. `"1,2,6"`) and 202 lines have no ID: both excluded.
- The numbers below are from `docs/stats_basic.json` (generated by `src/data/nuremberg_stats.py`); if they differ, trust the JSON.

## Decision
Main experiment: scribes with at least 150 lines (1, 2, 6, 7, 8, 9, 10).
Headline metrics: macro-F1 and balanced accuracy (the data is very imbalanced), plus per-scribe recall.
Split by page (or letter), never by line.
